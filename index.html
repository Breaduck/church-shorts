교회 쇼츠 편집기

편집기는 각자 PC 안에서 실행돼요.
AI 분석은 그 PC에 로그인된 본인 Claude 구독으로 돌아갑니다.

편집기 열기

켜져 있으면 자동으로 이동합니다. 꺼져 있다면 프로젝트 폴더의 편집기.bat 을 더블클릭하세요.

이 PC에 처음 설치한다면

⬇설치 파일 내려받기 (zip) 🔗GitHub에서 보기

git이 없어도 됩니다. 내려받아 압축을 풀면 끝.

  1. zip 압축을 풀고 폴더 안의 설치.bat 더블클릭
    (Python·ffmpeg·deno·Claude CLI를 확인하고 없으면 설치. 새로 설치된 게 있으면 창을 닫고 한 번 더.)
  2. 터미널에서 claude 를 한 번 실행해 본인 Claude 계정으로 로그인
  3. 편집기.bat 더블클릭 → 브라우저에 편집기가 열립니다

API 키를 주고받을 필요가 없어요. AI 사용량은 각자 구독에서 나갑니다.
